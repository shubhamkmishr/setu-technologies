# SETU Technologies

SETU Technologies is a Next.js App Router site for website development, AI automation, and custom software services.

## Stack

- Next.js 16 (App Router)
- React 19 and TypeScript
- Tailwind CSS 4
- ESLint 9 with the Next.js flat configuration

## Local Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Validation

```bash
npm run lint
npx tsc --noEmit
npm run build
```

## Contact Flow

The form validates the visitor's details and opens an email draft to `hello.setutechnologies@gmail.com`. It does not submit or deliver email automatically. Automatic delivery requires a server-side email provider integration and private credentials; no such integration is configured.

WhatsApp actions open `https://wa.me/919792234873` in a new tab.

## Site URL and Search Metadata

Set the server-side `SITE_URL` environment variable to the exact production origin after the domain is selected, for example `https://your-real-domain.example`. Do not use the example value literally. This enables the canonical URL and absolute sitemap reference. The sitemap is intentionally empty until `SITE_URL` is configured; `robots.txt` does not guess a production host.

The Open Graph preview is generated by `app/og/route.tsx`. Search metadata does not guarantee indexing; submit the deployed sitemap to the applicable webmaster tools after launch.

## Deployment Checklist

1. Choose and configure the production domain.
2. Set `SITE_URL` in the hosting provider's server environment.
3. Configure an email delivery provider if automatic enquiry delivery is required. Store credentials as server-only environment variables and add a server endpoint only as part of that integration.
4. Push the reviewed repository to GitHub and import it into Vercel.
5. Confirm the Vercel build command is `npm run build`, deploy from the intended production branch, then test the live domain, email draft flow, WhatsApp handoff, metadata, and sitemap.
