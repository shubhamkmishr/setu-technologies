# SETU Technologies

**Bridging Ideas and Technology**

SETU Technologies provides modern digital solutions for businesses, including website development, AI automation, and custom software development.

## Tech Stack

- Next.js 16 (App Router)
- React 19
- TypeScript
- Tailwind CSS 4
- ESLint 9

## Local Development

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open `http://localhost:3000` in your browser.

## Validation

Run these commands to validate the project:

```bash
npm run lint
npx tsc --noEmit
npm run build
```

## Deployment

This project can be deployed using Vercel.

Before production deployment:

1. Configure the production website URL using the `SITE_URL` environment variable.
2. Configure an email delivery provider if automatic email delivery is required.
3. Import the GitHub repository into Vercel.
4. Deploy and test the website, contact form, WhatsApp links, and metadata.
